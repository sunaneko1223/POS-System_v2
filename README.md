# POS-System

学校の地域祭り用に作った、オフライン対応のレジシステム(PWA)です。
特別な環境構築は不要で、`index.html` をブラウザで開くだけで動きます。

## 使い方(お店を開くとき)

1. このフォルダを丸ごとWebサーバー、または `index.html` を直接ブラウザで開く
2. スマホ/タブレット/PCなど、どの端末でも同じ画面が使えます
3. 一度読み込めば、機内モードやWi-Fiが無い状態でも会計処理はできます（PWA・オフライン対応）
4. 会計データを他の端末とまとめて集計したい場合だけ、Wi-Fi接続時に「サーバー連携」画面から送信します（サーバー機能は別途必要）

## 商品を変更したいとき

`data/item.yml` を編集してください。コードを触る必要はありません。

```yaml
- id: 1
  商品名: "焼きそば"
  値段: 100
```

商品を増やしたい場合は、この形式のまま `-` から始めてコピーして増やしてください。
（アプリ内の「商品管理」画面からも追加・削除できますが、次に `data/item.yml` を読み込み直すとその内容で上書きされる点に注意してください。恒久的に商品を変えたいときは `item.yml` を編集するのが確実です。）

## 集計サーバーのURLを変更したいとき

`data/serverlink.yml` を編集してください。

```yaml
server_url: "https://example.com"
```

- URLは常にこのファイルの値が使われます（アプリ画面からの個別変更はできません）。変更したい場合は、このファイルを書き換えてから配布・再読み込みしてください。

## ファイル構成

```
POS-System/
├── index.html              ... アプリ本体(画面・ロジックはすべてここに集約)
├── manifest.json            ... PWA設定
├── sw.js                    ... オフラインキャッシュ(Service Worker)
├── favicon.png               ... アイコン
├── data/
│   ├── item.yml              ... 商品データ(編集OK)
│   └── serverlink.yml         ... 集計サーバーのURL(編集OK)
├── fonts/                    ... フォント
└── library/                  ... 外部ライブラリ(そのまま使用)
    ├── dexie.js               ... IndexedDBラッパー(データ保存に使用)
    ├── js-yaml.min.js          ... YAML読み込み
    ├── tailwind.min.css        ... デザイン(見た目)
    └── fonts.css               ... フォント読み込み
```

## AIに修正・アップデートを頼みたいとき

このプロジェクトは、AIに `index.html` の内容を見せて相談しながら育ててきました。
コードが書けなくても、AI(Claudeなど)にこのフォルダを渡して

- 「〇〇画面の△△を直したい」
- 「新しく□□の機能を追加したい」

のように伝えれば、AIが `index.html` 内のコメント（`// ==================== 〇〇 ====================` の区切り）を目印に該当箇所を見つけて修正できます。ファイルは1つにまとまっていますが、コメントで機能ごとに区切ってあるので、AI・人間どちらから見ても場所を探しやすいはずです。

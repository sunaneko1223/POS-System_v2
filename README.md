# POS-System

本システムは、お会計上の計算ミスによるトラブル防止と店舗の回転率向上を目的とした計算代行システムです。なお、オートディスペンサーには対応しておりませんのであらかじめご了承ください。

## 注意事項

**インストール・起動について**
- 本システムはService Workerを利用しているため、初回は一度Webサイトへアクセスしてインストールする必要があります。端末のホーム画面アイコンだけでは開始できません。
- インストール後はアプリとして開けば、以降はインターネット環境がなくても利用できます(スタンドアローン方式)。
- データは端末内のIndexedDBに保存されるため、端末を再起動・シャットダウンしても消えません。

**データ同期について**
- オフライン状態での複数端末間のデータ同期はできません。
- 複数端末のデータをまとめたい場合は、オンライン環境でのみ集計サーバーへ送信することで対応してください。

**長時間使用時の注意**
- 長時間の連続使用により、端末が発熱し動作が不安定になる可能性があります(発熱により端末が停止した事例があります)。適宜休ませることをおすすめします。

## 使い方

### インストール
**開発者向け**
1. このリポジトリをForkします。
2. `settings>pages`に移動します。
3. BranchをNoneからmainに変更してsaveします。
4. 数分後、自動で専用のリンクが発行されます。
※Vercel等を使う場合はGithubでリンクを生成しなくて構いません。

**スタッフ向け**
1. 開発者向け4のリンクをGoogle Chromeで開きます。
2. 共有>ホーム画面に追加>Webアプリとして開くにチェックをオンにして追加します。
3. 追加されたアイコンを開くことができれば成功です。

## 商品を変更したいとき

`data/item.yml` を編集してください。コードを触る必要はありません。

```yaml
- id: 1
  商品名: "焼きそば"
  値段: 100
  種類: "ソース味"   # 任意項目。無くても動きます
```

商品を増やしたい場合は、この形式のまま `-` から始めてコピーして増やしてください。
（アプリ内の「商品管理」画面からも追加・削除できます。ここで追加した商品は端末内に保存され、`data/item.yml` を読み込み直しても消えません。ただし `item.yml` にある商品は再読み込みのたびに `item.yml` の内容で上書きされるので、既存商品の値段などを恒久的に変えたい場合は `item.yml` を編集してください。）

## 集計サーバーのURLを変更したいとき

`data/serverlink.yml` を編集してください。

```yaml
server_url: "https://example.com"
```

- URLは常にこのファイルの値が使われます（アプリ画面からの個別変更はできません）。変更したい場合は、このファイルを書き換えてから配布・再読み込みしてください。

## トラブルが起きたとき(エラーログ)

エラーが発生すると、画面に自動でログ画面がポップアップします。「コピー」ボタンでログをコピーできるので、開発者に報告する際はそのまま貼り付けてください。
ログ画面を閉じたあとでも、一度でもエラーが出ていれば画面右下に小さく「⚠ エラーログ」ボタンが出るので、そこからいつでも見返せます(何も起きていない時は表示されません)。

## ファイル構成

```
POS-System/
├── index.html              ... アプリ本体(画面・ロジックはすべてここに集約)
├── manifest.json           ... PWA設定
├── sw.js                   ... オフラインキャッシュ(Service Worker)
├── favicon.png             ... アイコン
├── data/
│   ├── item.yml            ... 商品データ(編集OK)
│   └── serverlink.yml      ... 集計サーバーのURL(編集OK)
├── fonts/                  ... フォント
└── library/                ... 外部ライブラリ(そのまま使用)
    ├── dexie.js            ... IndexedDBラッパー(データ保存に使用)
    ├── js-yaml.min.js      ... YAML読み込み
    ├── tailwind.min.css    ... デザイン(見た目)
    └── fonts.css           ... フォント読み込み
```

## AIに修正・アップデートを頼みたいとき

このプロジェクトは、Claudeと相談して開発しました。
コードが書けなくても、AI(Claudeなど)にこのフォルダを渡して

- 「〇〇画面の△△を直したい」
- 「新しく□□の機能を追加したい」

のように伝えれば、AIが `index.html` 内のコメントを目印に該当箇所をみつけて改変できます。
